# AI for Beginners: Large-Print Guide

Plain-English, step-by-step help using free AI — no jargon, no condescension, no prior experience needed.

## What this is

A beginner manual and large-print static HTML site for anyone who wants to start using free AI tools safely and privately. It covers:

- What AI is (and what it is not)
- How to chat safely
- Your first prompts
- Privacy basics
- Everyday tasks you can do with free AI

Written "like a friend would" — warm, clear, step by step, never talking down.

## Who this is for

Anyone new to AI, especially:

- Beginners who want large-print, easy-to-read materials
- Nurses and healthcare workers (education only — never medical advice)
- Small-business owners and authors (KDP, publishing, marketing, bookkeeping)
- People managing life-admin, paperwork, and budgeting
- Anyone wanting low-energy, ADHD-friendly productivity

## How to read it

Open any file in `site/` in a web browser. The site is static — no server, no install, no internet required once downloaded. Pages are large-print friendly with big text and high contrast.

## How to build

There is no build step. The HTML files are static and ready to use as-is. If you want to edit them, just open `site/assets/style.css` and any `.html` file in a text editor.
